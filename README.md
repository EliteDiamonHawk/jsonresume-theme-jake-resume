# JSON Resume Jake Theme Variants

This repository contains two independent JSON Resume theme projects:

- Minimal/ is the schema-only base theme.
- Extra/ is a standalone fork of Minimal with additional display controls:
  aliases, section ordering, censorship, display-date text, custom URL labels,
  and string locations.

Each folder is self-contained and includes its own implementation, sample
resume, tests, preview builder, package files, license, and README. Run npm
test or npm run preview from the theme folder you want to work on.

Visual design is inspired by Jake Gutierrez's LaTeX resume layout and the
sb2nov resume template.
